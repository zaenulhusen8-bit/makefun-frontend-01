A fast, dark-themed frontend for [make.fun](https://make.fun/bounty/makefun-frontend-01), built on live data with four surfaces: the bounty board (each bounty's reward or live pot, its entry fee, its time left and its entries), each bounty's own page (summary, rules, rewards table, dates, status), that bounty's leaderboard, and public account profiles. Hash-routed, dependency-free vanilla JS, readable on a phone.

## Run it

```sh
node serve.mjs
```

Then open http://localhost:8080 (pass `--port <n>` or set `PORT` for another port).
